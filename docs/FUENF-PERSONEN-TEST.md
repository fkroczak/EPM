# Fünf-Personen-Test am Tablet (Anleitung)

Empfehlung aus der UX-Prüfung vom 11.10.2026 (`docs/UX-PRUEFUNG-2026-10-11.md`). Fünf Personen aus der Praxis lösen je
eine Aufgabe ohne Hilfe; wer zuschaut, notiert, wo sie zögern. Das findet erfahrungsgemäß rund 80 % der
Bedienprobleme – mit etwa einer Stunde Aufwand.

## Vorbereitung (10 Minuten)

- Testsystem mit Musterdaten („Testdaten zurücksetzen“ unter Administration › System), nie echte Patienten.
- Ein Tablet (iPad oder Android, 10–11 Zoll) und ein Telefon. Die Testperson meldet sich mit dem Testzugang an
  (Rolle Mitarbeiter oder Mediziner, je nach Aufgabe).
- Eine zweite Person beobachtet und schreibt mit. Sie greift nicht ein und erklärt nichts – auch nicht auf Nachfrage.
  Erst nach der Aufgabe wird gesprochen.
- Je Person etwa 10 Minuten. Reihenfolge der Aufgaben mischen.

## Die fünf Aufgaben

Jede Aufgabe wird vorgelesen, nicht gezeigt. Gemessen werden: geschafft (ja / mit Umweg / nein), Zeit, Anzahl
Fehlklicks, Stellen des Zögerns (länger als 5 Sekunden ohne Aktion), Zitate („Wo ist …?“).

1. **Patient finden und Gewicht erfassen** – „Erika Musterfrau hat heute 63,2 kg. Trage das ein.“
   Erwartet: Suche oder Patientenliste → Akte → „Gewicht“ → speichern. Beobachten: Findet die Person die Suche oben?
   Sieht sie den Knopf „Gewicht“ im Aktenkopf?
2. **Neuen Patienten anlegen** – „Lege Hans Beispiel, geboren 3.3.1960, an. Mehr weißt du noch nicht.“
   Beobachten: Werden die drei Pflichtfelder erkannt? Fällt der eingeklappte Bereich „Weitere Angaben“ auf, und stört
   er? Wird „Anlegen“ am Ende des Formulars gefunden?
3. **Termin abhaken und Rückruf eintragen** – „Der Rückruf bei Max Mustermann ist erledigt. Trage ihn als erledigt
   ein und lege einen neuen Rückruf in zwei Wochen an.“
   Beobachten: Startseite („Heute zu tun“) oder Akte? Wird das Abhaken gefunden? Datumsfeld am Tablet verständlich?
4. **Medikament nachtragen** – „Erika Musterfrau nimmt neu Vitamin B12, 1000 µg, 1 Tablette morgens. Trage es ein.“
   Beobachten: Wird der Reiter „Medikamente“ gefunden (Reiterleiste scrollt am Tablet)? Ist die Dosierung
   „morgens – mittags – abends – nachts“ verständlich?
5. **Firma wechseln und Akte finden** (nur für Personen mit Zugang zu beiden Firmen) – „Du arbeitest jetzt für die
   Regeneration Clinic. Öffne die Akte von Hanna Test.“
   Beobachten: Wird der Umschalter unter dem Logo erkannt? Am Telefon: im Menü?

## Auswertung (15 Minuten)

| Aufgabe | Person 1 | Person 2 | Person 3 | Person 4 | Person 5 | Auffälligkeiten |
|---|---|---|---|---|---|---|
| 1 Gewicht | | | | | | |
| 2 Neuer Patient | | | | | | |
| 3 Termin | | | | | | |
| 4 Medikament | | | | | | |
| 5 Firma | | | | | | |

- Eine Stelle, an der **zwei oder mehr** Personen zögern oder scheitern, ist ein Bedienproblem – nicht die Schuld der
  Person.
- Je Problem eine Zeile in die Fehlerliste: Aufgabe, was die Person erwartet hat, was EPM gezeigt hat, Vorschlag.
- Nach den Änderungen denselben Test mit fünf anderen Personen wiederholen.

## Was nicht Gegenstand ist

Geschwindigkeit des Servers, Schulungswissen zu Infusionsplänen, Geschmack bei Farben. Es geht nur darum, ob die
Wege ohne Erklärung gefunden werden.
